# ProgramSpec

## Purpose

`ProgramSpec` is a safe DSL for extraction programs generated by the planner and programmer agents.

## Allowed Strategies

- `css`
- `xpath`
- `regex_on_text`
- `text_near_label`
- `llm_fallback`

## Allowed Postprocess Functions

- `strip`
- `normalize_whitespace`
- `normalize_date`

## Safety Rule

ProgramSpec must never execute arbitrary code. Do not use `eval` or `exec`.

## Implemented Status

The backend implements `ProgramSpec` and `FieldProgramSpec` as Pydantic models and executes them through a safe interpreter.

Implemented behavior:

- `css`: simple selector support for tag, `.class`, `#id`, `tag.class`, and `tag#id`
- `xpath`: limited `//tag` support mapped to the safe selector path
- `regex_on_text`: runs regex against normalized page text
- `text_near_label`: extracts text after labels such as `发布日期：...`
- `llm_fallback`: marks the allowed fallback strategy for a field. It is not
  executed during the deterministic pass; `FallbackDecider` triggers it only
  after verification identifies fields that need model assistance.

The executor only interprets the DSL and allowed postprocess functions. It does not call `eval` or `exec`.

## Example

```json
{
  "version": "0.1",
  "safety_mode": "dsl",
  "field_programs": [
    {
      "field_name": "publish_date",
      "strategy": "text_near_label",
      "label": "发布日期",
      "labels": ["publish_date", "发布日期", "发布时间"],
      "postprocess": ["strip", "normalize_whitespace", "normalize_date"]
    },
    {
      "field_name": "publish_date",
      "strategy": "llm_fallback",
      "postprocess": ["strip", "normalize_whitespace", "normalize_date"]
    }
  ]
}
```

This keeps deterministic extraction runnable without an API key while preserving
a real provider-backed fallback path for fields that fail verification.

## Reuse

Manual review can mark a ProgramSpec as user verified. The backend stores the
verified ProgramSpec by a stable schema signature and `programmer_agent_node`
reuses it for later extraction requests with the same schema shape. This provides
a concrete thesis demo path for ProgramSpec reuse without allowing arbitrary code.
