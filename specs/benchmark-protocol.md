# 评测方法与指标协议

状态：已实施的评测契约；关联验收：evaluation-center.feature。

## 数据与可复现性

- 每条样本显式携带 Schema、固定 HTML 输入和字段标注，不能按领域名从运行时模板库取 Schema。
- 保留的中文 HTML 样例属于实验数据，不会在启动时成为工作台模板。
- 标注答案、人工证据标注仅用于评分，不进入任何方法的输入。
- 固定数据版本、归一化规则、模型名称及调用参数；相同实验使用相同页面快照。
- 对 Direct LLM 的键名映射使用运行前声明的固定映射，不按答案动态改名或再用模型修答案。
- Schema 推断与 URL 采集端到端实验另列，不混入显式 Schema、固定 HTML 的消融结论。
- 程序类方法共享每条样本的初始 ProgramSpec，并记录其来源与签名，控制验证/修复变量。
- 冷启动禁用历史规则隐式复用；暖启动明确提供已验证规则并单列结果。
- 生成共享 ProgramSpec 的准备开销单列，不把该开销记为 Program Only 自身调用模型。

## 五种方法

| 方法 | 输入与行为 | 验证与修复 |
| --- | --- | --- |
| Direct LLM | 页面上下文和通用结构化抽取指令，不给 Schema、目标字段清单、别名或标注答案 | 无工作流验证和修复，不靠隐藏 ProgramSpec 或逐字段 Schema 提示生成预测 |
| LLM + Schema | 同一页面上下文和显式 Schema，模型生成字段记录 | 无程序抽取和验证后修复 |
| Program Only | 显式 Schema 与共享安全 ProgramSpec，仅运行确定性规则 | 不调用模型，不运行工作流验证器或修复 |
| Hybrid without Verifier | 相同确定性初始规则，仅对未得到值的字段启用模型 fallback | 无工作流验证器，无按验证问题修复 |
| Ours Full | 相同初始规则经过 LangGraph 主图，显式 Schema 不重新推断 | 运行验证器，根据问题定向 fallback，最多一次修复并重新验证 |

评分阶段可以计算字段类型、证据和 Schema 指标，但不得把评分结果反馈给预测方法；
离线评分不等于方法内部启用了 Verifier。

## 指标与计算

所有指标返回值及来源：`measured`、`estimated` 或 `unavailable`，不可用时值为空并说明原因。
分母为零时不可用，不填 1.0。若方法失败且没有预测，字段准确率和缺失率仍能按真实空预测计分，
但不能伪造置信度、Token 用量或证据精度。

| 指标 | 计算口径 |
| --- | --- |
| Field Accuracy | 与显式标注匹配的字段数 / 标注字段数，按预先声明的类型归一化与匹配规则比较 |
| Required Field Missing Rate | 缺失的必填字段数 / 样本 Schema 中必填字段总数，不用全部字段代替分母 |
| Schema Adherence | 通过的结构约束数 / 检查的结构约束总数；检查声明字段覆盖、必填非空、类型及无未知字段 |
| Evidence Precision | 经独立证据标注判断支持字段值的证据条数 / 提交证据条数；无独立标注则 unavailable |
| Evidence Coverage | 带至少一条证据的非空预测字段数 / 非空预测字段总数；不冒称证据精度 |
| Average Confidence | 有实际来源且合法的字段置信度平均值；单列缺失数量及启发式/模型来源，不等同正确率 |
| Actual Token Usage | 汇总服务商实际返回用量，未返回部分标记缺失，不用页面字数替代实际用量 |
| Estimated Token Cost | 以声明的估算公式计算并标为 estimated，不称实际账单；无调用的方法为真实零调用 |
| Runtime | 方法执行的实际墙钟耗时；单列共享采集/准备时间、样本数和聚合方式 |
| Program Reuse Rate | 实际读取并使用预先验证程序的程序类运行数 / 程序类运行总数；LLM-only 方法不适用 |
| Selective Accuracy | 达到事先声明的置信阈值且有有效预测的字段中正确字段数 / 被接受字段数，同时报告接受覆盖率 |
| Repair Success Rate | 修复后与标注匹配且修复前不匹配的尝试字段数 / 尝试修复字段数；没有尝试或非修复方法则 unavailable |

Schema Adherence 的约束列表和权重、列表值顺序语义、日期/数值比较规则、选择阈值须在实验配置中
声明并留存，不能看过结果后临时调整。不可用证据精度不影响实际证据覆盖率的计算。

## 失败与报告

各方法保存状态、错误、样本数、成功与失败计数。单方法失败不终止其余方法；
评测图完成并成功保存报告时任务可 completed，即使报告中有失败方法。
数据加载失败、指标计算无法完成或必要留存失败使评测任务 failed。

不使用固定 Schema 遵循度、不把构造规则等同复用、不以 accuracy 乘 missing rate 冒充选择性准确率。
报告必须记录数据和程序版本、模型参数、冷/暖设置、降级、实际调用、估算依据和不可用原因。
