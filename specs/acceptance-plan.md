# BDD 验收设计

状态：已落地并通过当前验收。依据为已确认决策、各 `.feature`、
后端 BDD/单元测试与前端生产构建；真实 CloakBrowser 渲染会在首次 URL 采集时
按配置自动准备固定版本 binary。

## 1. 背景

范围：取消内置模板、TOML 凭据、CloakBrowser 采集、异步可追踪任务、极简响应式状态界面、
公平评测与模块收敛。不新增登录、收费业务、分布式爬虫、验证码处理或任意代码执行。

```text
UI -> FastAPI feature routers -> injected LangGraph workflows
                                 |       |         |
                                 v       v         v
                            TOML settings browser   ModelAdapter
                                 |
                                 v
                         task/event/result persistence
```

## 2. 流程

Step1 用户输入 URL/HTML 及可选 Schema，服务校验提交内容。

Step2 服务保存最小任务元数据，返回 202 回执；后台执行注入的 LangGraph 工作流。

Step3 每个节点发布开始和终结事件，客户端查询状态及增量事件。

Step4 页面采集使用 CloakBrowser 或明确标记的 HTTP 降级；显式 Schema 的确定性抽取可离线完成。

Step5 验证结果与任务状态独立，运行规则模式只在显式允许时对字段调用模型修复。

Step6 保存终态和可用结果，客户端停止任务刷新；重启或重试遵循统一恢复契约。

## 3. 接口

接口、HTTP 状态与标识语义见 [runtime-contract.md](./runtime-contract.md)。
Schema 校验保持独立的合法/非法结果；人工复核和规格修订不自动改变原任务终态。

DTO 精确 JSON 字段布局、事件分页上限和公开配置入口路径已由
`specs/runtime-contract.md`、Pydantic contracts 与 `/api/config` 实现。
配置错误只报项路径和脱敏原因，任务不存在 404，输入非法 422，提交接受 202。

## 4. 业务规则

| 编号 | 可证伪规则 | 场景归属 |
| --- | --- | --- |
| R1 | 空库启动不创建模板，历史同名 Schema 不删除 | schema |
| R2 | 凭据只从 TOML 使用，不被环境覆盖或出现在公开数据 | configuration |
| R3 | URL 渲染使用 CloakBrowser，降级留痕且无旧浏览器隐式替换 | page |
| R4 | 接受任务后可回查 running 事件，completed 不等于质量通过 | extraction、observability |
| R5 | 已验证规则默认零模型调用，显式修复不改规则 | extraction、UI |
| R6 | 刷新不重提，重启不自动续跑，重试不覆盖原任务 | observability、UI |
| R7 | 对照方法隔离答案，真实指标不以占位值代替 | evaluation |

重复刷新零新增任务，显式重试新增关联任务；游标回查无重复消费或事件丢失。
端到端延迟、并发容量和性能目标未指定，不据此宣称达标；刷新/导航超时配置在实施前明确。

## 5. 持久化

核查任务 ID、关联 ID、父任务、状态、非敏感配置快照、事件顺序、开始/终结时间和可用结果。
核查旧任务、Schema 版本、人工规则未被删除；原失败任务在重试后内容不变。

业务网页载荷与日志分别留存；不向任一任务记录写入模型密钥、许可或数据库密码。
具体新表名和索引未定，实施阶段以真实迁移契约验收，不在此虚构表结构。

## 6. 边界条件

- config.toml 不存在、解析失败、配置值非法、密钥为空、异常文字包含测试凭据。
- 浏览器未准备、启动失败、导航超时、空白页、访问拒绝、HTTP 降级允许/禁止。
- Schema 无法生成、必填缺失、证据错误、修复失败、结果留存失败。
- queued/running 浏览器刷新、状态断网恢复、迟到旧响应、后端重启和显式重试。
- 评测一条样本缺 Schema、一个方法失败、无证据标注、无 Token 回执或指标零分母。
- 320px、767px、768px、1199px 和宽桌面，长文本、键盘焦点与减少动态效果。
- 使用无害测试凭据和页面字符串核查脱敏、文本转义与白名单输出，不向真实外部站点注入测试载荷。

## 7. 日志与排障

优先通过 task_id/correlation_id 定位状态，然后按节点顺序查采集器、配置版本、
模型调用目的、规则签名、字段修复结果和终态原因。
错误日志必须含上下文但不含测试凭据；节点未结束时不能伪造 end_time 或最终耗时。

示例为目标日志语义，不是已有日志格式：

```text
task=<test-id> node=schema_agent_node status=failed reason=model_not_configured
```

## 8. 测试建议

先写失败 BDD 步骤再实现，按能力索引绑定 `.feature`，补有风险的单元和浏览器行为测试。
默认使用临时 TOML、隔离存储、假模型与假浏览器，绝不读取本地真实密钥或触发收费调用。

| 验收组 | 正向 | 反向或恢复 |
| --- | --- | --- |
| Schema | 自定义校验、历史读取 | 空库不种模板、无模型无 Schema 明确失败 |
| TOML | 正确设置与凭据加载 | 环境覆盖无效、缺文件和敏感错误脱敏、构建不带凭据 |
| 浏览器 | CloakBrowser 固定页面采集 | 超时/缺二进制、禁止降级、许可不可用时不伪装可用 |
| 运行 | 202 回执、节点实时事件、终态读取 | 部分失败、旧事件不回退、状态写入失败不接受任务 |
| UI | 任务恢复、自动刷新与布局 | 断网保留旧值、质量不通过、长文本及键盘可用 |
| 评测 | 五方法、显式标注、实际计分 | 答案泄露、错误证据、不可用指标、冷/暖混淆 |

CloakBrowser 的 Windows 与 Linux Docker 自动下载与渲染烟测在依赖准备后单独运行；
真实服务商评测必须由用户提供本地配置并明确启动，不能混入默认离线 BDD。
当前离线验收已执行后端全量 pytest 与前端 `npm run build`，外部浏览器二进制烟测除外。
